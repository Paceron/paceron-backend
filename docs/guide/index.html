Autenticación

Los endpoints protegidos requieren un token JWT en el header:

Authorization: Bearer <access_token>

Flujo

  1. Registrarse en POST /api/v1/auth/register o usar credenciales existentes
  2. Autenticarse en POST /api/v1/auth/login → obtienes access_token y refresh_token
  3. Usar access_token en el header Authorization: Bearer para endpoints protegidos
  4. El access_token expira en 1 hora. Usar refresh_token para obtener uno nuevo (próximamente)

Errores estándar

Todos los endpoints devuelven errores con esta estructura:

{
  "status_code": 400,
  "code": "Bad request",
  "message": "descripción del error"
}
