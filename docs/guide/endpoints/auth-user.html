GET /api/v1/auth/user

Devuelve los datos del usuario autenticado según el token JWT.

Request

HeaderValorObligatorio
AuthorizationBearer <access_token>Sí

No requiere body.

Response

200 OK

{
  "user_id":     1,
  "name":        "John",
  "surname":     "Doe",
  "email":       "john@example.com",
  "dni":         "12345678",
  "birth_date":  "15/04/1990",
  "status":      "active"
}

Los campos opcionales se omiten si no tienen valor.

Errores posibles

CódigoStatusCausa
Unauthorized401Token ausente, inválido o expirado
Internal Server Error500Usuario no encontrado en BD
