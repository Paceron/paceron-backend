POST /api/v1/auth/login

Autentica un usuario con email y contraseña. Devuelve tokens JWT para acceder a endpoints protegidos.

Request

HeaderValorObligatorio
Content-Typeapplication/jsonSí
{
  "email":    "john@example.com",
  "password": "SecurePass1"
}
CampoTipoObligatorioDescripción
emailstringSíEmail del usuario
passwordstringSíContraseña

Response

200 OK

{
  "authorization": {
    "access_token":  "eyJhbGciOi...",
    "refresh_token": "eyJhbGciOi...",
    "expires_in":    3600
  },
  "user": {
    "user_id":  1,
    "name":     "John",
    "email":    "john@example.com",
    "status":   "active"
  }
}
CampoTipoDescripción
authorization.access_tokenstringJWT de acceso (expira en 1h)
authorization.refresh_tokenstringJWT de refresco (expira en 7d)
authorization.expires_inintTiempo de expiración en segundos
userobjectDatos completos del usuario

Errores posibles

CódigoStatusCausa
Bad request400Body inválido
Unauthorized401Email no encontrado, usuario inactivo, o contraseña incorrecta
Internal Server Error500Error al generar tokens o consultar BD

Por seguridad, todos los errores de autenticación devuelven el mismo mensaje: "No se pudo autenticar"
