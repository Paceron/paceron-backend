PATCH /api/v1/users/{id}/status

Cambia el estado de un usuario a active o inactive.

Request

HeaderValorObligatorio
Content-Typeapplication/jsonSí
AuthorizationBearer <access_token>Sí
ParámetroTipoUbicaciónDescripción
idintpathID del usuario
{
  "status": "active"
}
CampoTipoObligatorioDescripción
statusstringSí"active" o "inactive"

Response

200 OK

{
  "status_code": 200,
  "code":       "Success",
  "message":    "ok"
}

Errores posibles

CódigoStatusCausa
Bad request400Body inválido
Bad request400Status inválido (no es active/inactive)
Unauthorized401Token ausente o inválido
Internal Server Error500Usuario no encontrado o error de BD
