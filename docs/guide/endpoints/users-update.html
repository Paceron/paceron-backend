PUT /api/v1/users/{id}

Actualiza los datos de un usuario. Solo se envían los campos que se desean modificar (actualización parcial).

Request

HeaderValorObligatorio
Content-Typeapplication/jsonSí
AuthorizationBearer <access_token>Sí
ParámetroTipoUbicaciónDescripción
idintpathID del usuario a actualizar
{
  "name":      "John Updated",
  "phone":     "555555555",
  "province":  "Córdoba",
  "city":      "Córdoba"
}
CampoTipoObligatorioDescripción
namestringNoNombre
surnamestringNoApellido
emailstringNoEmail
phonestringNoTeléfono
phone_contactstringNoTeléfono alternativo
countrystringNoPaís
provincestringNoProvincia
citystringNoCiudad
streetstringNoCalle
numberstringNoNúmero
dnistringNoDNI
birth_datestringNoDD/MM/YYYY

Response

200 OK

{
  "user_id":  1,
  "name":     "John Updated",
  "email":    "john@example.com",
  "status":   "active",
  "province": "Córdoba"
}

Errores posibles

CódigoStatusCausa
Bad request400Body inválido
Unauthorized401Token ausente o inválido
Internal Server Error500Usuario no encontrado o error de BD
