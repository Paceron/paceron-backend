POST /api/v1/auth/register

Registra un nuevo usuario en el sistema. La contraseña se valida con los siguientes requisitos:

  • Mínimo 8 caracteres
  • Al menos 1 letra mayúscula
  • Al menos 1 letra minúscula
  • Al menos 1 dígito

Request

HeaderValorObligatorio
Content-Typeapplication/jsonSí
{
  "name":         "John",
  "surname":      "Doe",
  "email":        "john@example.com",
  "dni":          "12345678",
  "birth_date":   "15/04/1990",
  "password":     "SecurePass1",
  "phone":        "123456789",
  "phone_contact":"987654321",
  "country":      "Argentina",
  "province":     "Buenos Aires",
  "city":         "La Plata",
  "street":       "Calle Falsa",
  "number":       "123"
}

dnistringSíDNI
